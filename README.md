# ULTRA NET

تطبيق أندرويد (Flutter) لفحص الإنترنت والاستفادة من أقصى سرعة يوفرها خطك.

## المزايا
- فحص نوع الاتصال (Wi-Fi / بيانات / سلكي) مباشرة.
- قياس زمن الاستجابة (Ping) بدقة.
- قياس التنزيل والرفع بعدة اتصالات متوازية مع السرعة الحية وأعلى سرعة.
- **Turbo**: تنزيل أي ملف عبر 4 / 8 / 16 اتصالاً متوازياً.
- **تحسين الهاتف كله**: تشخيص ذكي لنتائجك، مقارنة مزودي DNS (يسرّع فتح المواقع في كل التطبيقات والمتصفحات)، واختصارات لإعدادات الهاتف المؤثرة على السرعة.

## ملاحظات
- لا يوجد تطبيق يستطيع رفع سرعة باقتك؛ الصفحة تزيل العوائق فقط (DNS بطيء، تطبيقات تستهلك الخلفية، توفير بيانات/طاقة).
- روابط Turbo يجب أن تكون `https://` ومباشرة، والخادم يدعم `Range` ليعمل التسريع.
- ملفات Turbo تُحفظ في مجلد التطبيق: `Android/data/com.ultranet.app.ultra_net/files/UltraNet`.
- الاختبار يستهلك بيانات (عشرات الميغابايتات).

## البناء
يُبنى ملف APK تلقائياً من تبويب Actions (Build Ultra Net APK) ويظهر في Artifacts.
