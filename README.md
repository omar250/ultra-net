# ULTRA NET

تطبيق أندرويد (Flutter) لفحص الإنترنت والاستفادة من أقصى سرعة يوفرها خطك.

## المزايا
- فحص نوع الاتصال (Wi-Fi / بيانات / سلكي) مباشرة.
- قياس زمن الاستجابة (Ping) بدقة (اتصال واحد مُسخَّن + وسيط 5 عينات).
- قياس التنزيل والرفع بعدة اتصالات متوازية مع عرض السرعة الحية وأعلى سرعة.
- **Turbo**: تنزيل أي ملف عبر 4 / 8 / 16 اتصالاً متوازياً (Range requests) لاستغلال كامل عرض النطاق.

## ملاحظات
- التطبيق لا يستطيع تجاوز سرعة باقتك؛ Turbo يمنع فقط أن يكون الاتصال الواحد هو عنق الزجاجة.
- روابط Turbo يجب أن تكون `https://` ومباشرة، والخادم يجب أن يدعم `Range` لتفعيل التسريع (وإلا يُنزَّل باتصال واحد).
- الملفات تُحفظ في مجلد التطبيق: `Android/data/com.ultranet.app/files/UltraNet`.
- الاختبار يستهلك بيانات (عشرات الميغابايت)؛ انتبه عند استخدام بيانات الهاتف.
